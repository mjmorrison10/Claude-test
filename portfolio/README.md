## What to capture per clip
- **Source:** the original episode/video (link).
- **Clip:** the finished file or a link (store files in Drive; link them here).
- **For:** client name, or "spec" if it's a free sample / self-initiated.
- **Result:** any performance data we can get later — views, saves, whether it landed the client. Backfill this over time.

Once we have ~8–10 solid clips, compile a **before/after reel** and a simple portfolio page (Canva or a one-page site) to link in outreach and DMs. That reel becomes the new top-of-funnel proof that replaces the lost accounts.
