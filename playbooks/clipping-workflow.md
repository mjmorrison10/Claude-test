# Playbook: Clipping Workflow

_How a long-form piece becomes finished shorts._

## Inputs
- Source video/audio (URL or file) — a podcast episode, YouTube video, or livestream.
- Target count and platform (IG Reels / TikTok / Shorts — usually the same vertical clip works for all).

## Steps

### 1. Import
Bring the source into Descript. **Standard intake:** the Google Drive folder **"Clip Sources — drop raw videos here"** (https://drive.google.com/drive/folders/1n7uljxPBx9IffGvgj69pMmj4f5PKzNbJ). Owner or client drops a raw video there; Descript imports Drive links natively. (Direct file links and Dropbox also work. Note: YouTube URLs do NOT import directly — grab the file first.)

### 2. Find the moments
Read the transcript and mark the highest-potential moments. Good clip DNA for this niche:
- A **strong opinion / hot take** ("Most men fail because…").
- A **story or transformation** with tension and payoff.
- A **contrarian or pattern-interrupt** line that hooks in the first 2 seconds.
- An **actionable tip** that stands alone without context.

Prioritize moments that *sell the creator's worldview* — those drive followers and buyers, not just views.

### 3. Cut
- Vertical, ~20–60 seconds.
- Hook first. If the best line is 40s in, consider opening on it.
- Trim filler, dead air, "um"s.

### 4. Caption & polish
- Burned-in captions (essential for silent autoplay).
- Clear, readable style. Optional: simple brand color / the creator's name.
- A hook headline on-screen for the first few seconds.

### 5. Export & deliver
- Export vertical MP4.
- Save to the client's Drive folder (or attach for a free sample).

### 6. Log it
Add to [`portfolio/`](../portfolio/): source, clip, client (or "spec"), date, and any performance data we get later. **Always.**

## Quality bar
Would this clip make *us* stop scrolling? If not, recut. Our name is on every clip that goes out — this is how we rebuild proof, so the floor is "genuinely good," not "good enough."
